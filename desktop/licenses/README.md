# Bundled dependency notices

The project software is GPL-3.0-or-later; original documentation, artwork and sample STEP geometry are CC BY 4.0. Project licence texts are included here during the build.

Third-party components retain their own licences. Numerical package notices and exact Python versions are collected by tools/collect_licenses.py; Rust package notices come from the local Cargo registry. Cargo.lock pins the Rust dependency graph, package-lock.json pins JavaScript build tooling.

See THIRD_PARTY_NOTICES.md in this folder for upstream sources and attribution. The release dependency-sources directory supplies Gmsh/OpenCASCADE source archives. No user geometry or saved results is bundled.
